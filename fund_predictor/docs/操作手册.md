# 基金预测/回测系统操作手册（新手版）

> 适用对象：第一次接触本项目的同学。  
> 阅读目标：看完后你能知道**这是什么、有什么用、怎么从0开始跑起来**。

---

## 0. 这是什么？能帮你做什么？

这个项目是一个**基金研究与操作辅助工具**，不是自动交易程序。它能帮你做 4 件事：

1. **自动拉取基金历史净值数据**（支持增量更新）；
2. **按规则计算买入信号并做历史回测**；
3. **输出报告**（Markdown / HTML / JSON / CSV）；
4. **记录你的本地交易账本**（买入、卖出、部分卖出、收益统计）。

简单理解：
- 你可以把它当成一个“研究+记账”的命令行小助手；
- 它给你的是“量化参考”，**不是投资建议**。

---

## 1. 使用前你需要知道的 3 个目录

运行后最常接触这几个路径：

- `config.yaml`：系统配置文件（数据源、参数、路径等）；
- `data/meta/funds.json`：基金池（你想分析哪些基金）；
- `output/reports/`：报告输出目录。

交易相关：
- `data/meta/portfolio.json`：本地交易账本（持仓、流水、已实现收益）。

---

## 2. 先做这一步：配置基金池

编辑 `data/meta/funds.json`。

支持两种格式：

### 格式 A（最简单）
```json
["009689", "005827"]
```

### 格式 B（推荐，可带名称）
```json
[
  {"fund_code": "009689", "fund_name": "某某基金A"},
  {"fund_code": "005827", "fund_name": "某某基金B"}
]
```

当你不在命令行传 `--funds` 时，系统会自动读取这个文件。

## 4. 命令总览（按场景分组）

## 4.1 数据/分析类

### `analyze` 一体化分析
```bash
python main.py analyze
```
作用：更新数据 -> 计算特征 -> 回测 -> 输出报告。

常用参数：
```bash
python main.py analyze --funds 009689 005827
python main.py analyze --fund-file funds.txt
```

### `update-data` 仅更新净值数据
```bash
python main.py update-data
```

### `backtest` 仅回测（当前实现复用 analyze 流程）
```bash
python main.py backtest
```

### `daily-run` 一键日常流程
```bash
python main.py daily-run
```
作用：等价于先执行 `analyze` 再执行 `profit-summary`。

### `report --latest` 查看最新报告路径
```bash
python main.py report --latest
```

---

## 4.2 交易账本类

### `init-db` 初始化数据库
```bash
python main.py init-db
```

重置（会清空历史）：
```bash
python main.py init-db --reset
python main.py init-db --reset --yes
```
> `--yes` 表示跳过二次确认。

### `buy` 买入/加仓
```bash
python main.py buy --fund-code 009689 --fund-name 某某基金 --trade-date 2026-04-27 --price 1.235 --shares 1000
```

### `track` 更新跟踪信息（止盈/止损/备注）
```bash
python main.py track --fund-code 009689 --take-profit 0.12 --stop-loss -0.08 --note "波段跟踪"
```

### `sell` 卖出
```bash
python main.py sell --fund-code 009689 --price 1.36 --shares 500
python main.py sell --fund-code 009689 --price 1.36 --shares 500 --yes
```

### `partial-sell` 部分卖出
```bash
python main.py partial-sell --fund-code 009689 --price 1.40 --shares 200
python main.py partial-sell --fund-code 009689 --price 1.40 --shares 200 --yes
```

### `undo-last` 撤销最近一笔订单
```bash
python main.py undo-last
python main.py undo-last --yes
```

### `positions` 查看当前持仓
```bash
python main.py positions
```

### `history` 查看最近交易流水
```bash
python main.py history --limit 50
```

### `profit-summary` 查看收益
```bash
python main.py profit-summary
```
输出包含：
- 已实现收益（历史卖出）；
- 未实现收益（当前持仓）；
- 总收益；
- 详细表格明细。

## 5. 交互控制台（最适合新手）

启动：
```bash
python main.py console
```

菜单：
- 1 整体跑一遍
- 2 跟踪
- 3 买入
- 4 卖出
- 5 部分卖出
- 6 初始化数据库
- 7 查询收益
- 8 撤销最近订单
- 0 退出

新手建议：优先用控制台，按提示一步步输入，不容易漏参数。

控制台便捷点：
- 会记住最近一次基金代码，可回车复用；
- 数值输入支持重试，输入错误可重新输入。

## 6. 报告怎么看（最关键）

每次分析后会在 `output/reports/` 生成：

- `report_时间戳.md`
- `report_时间戳.html`
- `report_时间戳.json`
- `trades_时间戳.csv`

建议新手阅读顺序：
1. 先看 Markdown/HTML 的摘要；
2. 再看单基金排名与信号强度；
3. 最后看交易明细 CSV 做复盘。

---

## 7. 收益统计规则（务必理解）

1. **已实现收益**：只统计历史卖出/部分卖出；
2. **未实现收益**：只统计当前还持有的仓位；
3. 卖出后不再计入未实现收益，但历史已实现收益会保留；
4. 撤销订单会回滚对应账本状态（按支持范围处理）。

## 8. 常见问题（FAQ）

### Q1：为什么 `analyze` 没给我结果？
可能原因：
- 基金代码无效；
- 网络请求失败；
- 样本不足（交易数不足、历史数据太短）。

建议先执行：
```bash
python main.py update-data
```
再执行：
```bash
python main.py analyze
```

### Q2：输入数字报错怎么办？
- 在 `console` 模式会自动重试；
- 在命令行模式请检查 `--price`、`--shares` 是否为数字。

### Q3：如何避免误清仓？
- 默认命令有二次确认；
- 批处理脚本才建议加 `--yes`。

### Q4：这能直接给我买卖建议吗？
- 它给的是历史统计和规则信号，主要用于研究辅助；
- 不构成投资建议，实盘请自行判断风险。

## 9. 推荐日常操作流程（实用）

每天 1 次：

1. `python main.py daily-run`
2. `python main.py positions`
3. 根据需要执行 `track / sell / partial-sell`
4. 收盘后 `python main.py history --limit 20` 复盘
