# 基金预测/回测系统操作手册（新手版）

> 适用对象：第一次接触本项目的同学。  
> 阅读目标：看完后你能知道**这是什么、有什么用、怎么从0开始跑起来**。

---

## 0. 这是什么？能帮你做什么？

这个项目是一个**基金研究与操作辅助工具**，不是自动交易程序。它能帮你做 4 件事：

1. **自动拉取基金历史净值数据**（支持增量更新）；
2. **按规则计算买入信号并做历史回测**；
3. **输出报告**（Markdown / HTML / JSON / CSV）；
4. **记录你的本地交易账本**（买入、卖出、部分卖出、收益统计）。

简单理解：
- 你可以把它当成一个“研究+记账”的命令行小助手；
- 它给你的是“量化参考”，**不是投资建议**。

---

## 1. 使用前你需要知道的 3 个目录

运行后最常接触这几个路径：

- `config.yaml`：系统配置文件（数据源、参数、路径等）；
- `data/meta/funds.json`：基金池（你想分析哪些基金）；
- `output/reports/`：报告输出目录。

交易相关：
- `data/meta/portfolio.json`：本地交易账本（持仓、流水、已实现收益）。

---

## 2. 先做这一步：配置基金池

编辑 `data/meta/funds.json`。

支持两种格式：

### 格式 A（最简单）
```json
["009689", "005827"]
```

### 格式 B（推荐，可带名称）
```json
[
  {"fund_code": "009689", "fund_name": "某某基金A"},
  {"fund_code": "005827", "fund_name": "某某基金B"}
]
```

当你不在命令行传 `--funds` 时，系统会自动读取这个文件。

## 3. 3 分钟快速上手（最小闭环）

下面是最推荐的新手路径：

### 第 1 步：初始化交易账本
```bash
python main.py init-db
```

### 第 2 步：跑一遍分析并生成报告
```bash
python main.py analyze
```

### 第 3 步：查看最新报告
```bash
python main.py report --latest
```

### 第 4 步：录入一笔买入
```bash
python main.py buy --fund-code 009689 --fund-name 某某基金 --trade-date 2026-04-27 --price 1.235 --shares 1000
```

### 第 5 步：查看收益概览
```bash
python main.py profit-summary
```

## 4. 命令总览（按场景分组）

## 4.1 数据/分析类

### `analyze` 一体化分析
```bash
python main.py analyze
```
作用：更新数据 -> 计算特征 -> 回测 -> 输出报告。

常用参数：
```bash
python main.py analyze --funds 009689 005827
python main.py analyze --fund-file funds.txt
```

### `update-data` 仅更新净值数据
```bash
python main.py update-data
```

### `backtest` 仅回测（当前实现复用 analyze 流程）
```bash
python main.py backtest
```

### 1.4 查看最近报告
```bash
python main.py report --latest
```

### 1.5 初始化数据库
```bash
python main.py init-db
python main.py init-db --reset
python main.py init-db --reset --yes
```

### 1.6 买入/跟踪/卖出/部分卖出
```bash
python main.py buy --fund-code 009689 --fund-name 某某基金 --trade-date 2026-04-27 --price 1.235 --shares 1000
python main.py track --fund-code 009689 --take-profit 0.12 --stop-loss -0.08 --note "波段跟踪"
python main.py sell --fund-code 009689 --price 1.36 --shares 500
python main.py partial-sell --fund-code 009689 --price 1.40 --shares 200
# 自动确认（跳过 yes 二次确认）
python main.py sell --fund-code 009689 --price 1.36 --shares 500 --yes
python main.py partial-sell --fund-code 009689 --price 1.40 --shares 200 --yes
```

### 1.7 持仓/流水/收益
```bash
python main.py positions
python main.py history --limit 50
python main.py profit-summary
```

## 2. 交互控制台

启动：
```bash
python main.py console
```

菜单：
- 1 整体跑一遍
- 2 跟踪
- 3 买入
- 4 卖出
- 5 部分卖出
- 6 初始化数据库
- 7 查询收益
- 0 退出

示例：
- 输入 `3` -> 买入；
- 依次输入基金代码、基金名称（可留空）、买入日期、买入净值、买入份额；
- 系统自动写入本地交易账本。
- 控制台会记住最近一次输入的基金代码，后续步骤可直接回车复用。

## 3. 收益统计规则

1. **已实现收益**：仅统计历史卖出/部分卖出记录；
2. **未实现收益**：仅统计当前仍持仓的基金；
3. 卖出后不再把该笔仓位计入未实现收益，但其历史收益会保留在已实现收益明细中。
4. `profit-summary` 以表格方式展示明细字段，便于快速阅读。

## 4. 关键文件

- 配置：`config.yaml`
- 基金池：`data/meta/funds.json`
- 交易账本：`data/meta/portfolio.json`
- 抓取状态：`data/meta/fetch_status.json`
- 调参历史：`data/meta/tuning_history.jsonl`
- 报告目录：`output/reports/`
